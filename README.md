# Rex Sessions for Raycast

List your [Rex](https://www.superlogical.com/rex) sessions in Raycast and switch to one.

## Requirements

- Rex Beta installed in `/Applications`
- Remote Control turned on in Rex: **Settings → Rex Server → Remote Control**

## Install

```sh
git clone https://github.com/marcosktsz/rex-raycast.git
cd rex-raycast
npm install
npm run dev
```

`npm run dev` adds the extension to Raycast. Once it says `built extension successfully`, stop it with Ctrl-C; the extension stays installed.

Open Raycast and run **Rex Sessions**.
